# 💚 SmartHealth AI

A health risk assessment web application built using HTML, CSS, and JavaScript. It allows users to enter health information, select a disease, provide symptoms and health measurements, calculate a risk score, view recommendations, and export an assessment report.

---

## ✨ Features

- Personal health information form
- Disease and symptom selection
- Health risk score calculation
- Risk visualization using charts
- Health recommendations
- English, Hindi, and Marathi language support
- Voice assistance
- PDF report export
- CSV report export
- Responsive user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- jsPDF
- Web Speech API

---

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter the required information.
4. Select a disease and symptoms.
5. Calculate the risk score.
6. View the assessment and export the report if required.
