# 💚 SmartHealth AI

**SmartHealth AI** is a frontend-based health risk assessment web application developed using **HTML, CSS, and JavaScript**. The application allows users to enter health information, select a health condition, provide symptoms and health measurements, calculate a risk score, view health recommendations based on the assessment, and export the assessment report.

> **Note:** This project is developed for educational purposes and is not intended to provide medical diagnosis or treatment.

---

## ✨ Features

* 👤 Personal health information form
* 🩺 Disease and symptom selection
* 📊 Health risk score calculation
* 📈 Risk visualization using interactive charts
* 💡 Health recommendations based on the assessment
* 🌐 English, Hindi, and Marathi language support
* 🎙️ Voice assistance using browser speech APIs
* 📄 PDF assessment report export
* 📑 CSV report export
* 📱 Responsive and user-friendly interface

---

## 🛠️ Technologies Used

| Technology         | Purpose                                 |
| ------------------ | --------------------------------------- |
| **HTML5**          | Webpage structure and semantic elements |
| **CSS3**           | Styling, layout, and responsive design  |
| **JavaScript**     | Application logic and interactivity     |
| **Chart.js**       | Risk score visualization                |
| **jsPDF**          | PDF report generation                   |
| **Web Speech API** | Voice assistance and speech features    |

**Risk scoring:** Rule-based calculation using health measurements and selected symptoms.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/vaibhaviboche/SmartHealth-AI.git
```

### 2. Open the project

Navigate to the project folder and open:

```text
index.html
```

in a modern web browser.

### 3. Use the application

1. Enter the required health information.
2. Select a disease or health condition.
3. Enter the required symptoms and measurements.
4. Calculate the risk score.
5. Review the assessment and recommendations.
6. Export the report as PDF or CSV if required.
